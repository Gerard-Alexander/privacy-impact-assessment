# Privacy Impact Assessment 

Privacy Impact Assessment (PIA) System


# Tech Stack
Backend: Node.js + Express
Templating Engine: EJS
Database: MySQL
ORM: Prisma
Other Tools: Nodemon (development)

# Set-up Installation
1. Clone the repository:
2. git clone https://gitlab.com/2215699/privacy-impact-assessment.git
3. cd project or Choose Folder

# Install dependencies:
4. npm install
5. Setup environment variables:
6. DATABASE_URL="mysql://root:password@localhost:3306/pia_db"
7. Run Prisma migrations:
8. npx prisma migrate dev
9. Start the server:
10. npm run dev
